# Cedarwood Close

Static website for Cedarwood Close LLC.

## Deployment

This repository is designed to deploy from the `main` branch root using GitHub Pages.

- Canonical domain: `cedarwood.vc`
- Forwarded domains: `c-c.vc`, `cedarwoodclose.com`
- GitHub Pages source: `main` branch, `/`

## Local Preview

```sh
python3 -m http.server 4173
```

Then open `http://localhost:4173`.
